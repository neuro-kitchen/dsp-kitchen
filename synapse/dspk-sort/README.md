# dspk-sort

What every dspk spike sorter shares: `result/` (the sort's result), `windows/` (recording windows
streamed to the device, stored integers uploaded as they are, preprocessed there), `stats/`, and
`components/` (detection, matching, clustering, templates) ported from SpikeInterface.
