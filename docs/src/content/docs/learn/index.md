dsp-kitchen processes multi-channel recordings on any GPU or the CPU. These pages take you from
installing it to working on whole recordings, a short page at a time.

| Chapter | After it, you can |
|---|---|
| [Get started](/dsp-kitchen/learn/get-started/install/) | Install dsp-kitchen, see which devices it can use, and filter a signal |
| [Concepts](/dsp-kitchen/learn/concepts/runtimes/) | Say what a runtime, a halo and a pyramid are, and why results don't depend on either |
| [Python](/dsp-kitchen/learn/python/recordings/) | Read recordings, run operations and pipelines, and bring your own functions |
| [Course](/dsp-kitchen/learn/course/) | Work through worked examples whose answers are known, each with its figure |
