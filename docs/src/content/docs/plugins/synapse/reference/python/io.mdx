Probes (site geometry: presets, probe files, channel maps) and sortings (Phy / Kilosort folders,
`.sorting.zarr`, NWB `/units`).

A [`Probe`](/dsp-kitchen/plugins/synapse/reference/python/io/#probe) follows a recording's channels: [`remap`](/dsp-kitchen/reference/python/ops-layout/#remap) applies a channel map (see
[`ops.layout`](/dsp-kitchen/reference/python/ops-layout/)), `depth_order` gives the map that sorts channels by depth.
A [`Sorting`](/dsp-kitchen/plugins/synapse/reference/python/io/#sorting) holds units with their spike trains, templates and quality metrics.

## Classes

### `Probe`

A probe's geometry: the position of the site under every recording channel.

Positions are in µm, `y` is depth. Make one with `preset`, `grid`,
`from_positions`, [`read_probe_file`](/dsp-kitchen/plugins/synapse/reference/python/io/#read_probe_file) or [`probe_of`](/dsp-kitchen/plugins/synapse/reference/python/io/#probe_of).

**Examples**

```python
>>> import dspk
>>> probe = dspk.synapse.io.Probe.preset("tetrode")
>>> len(probe)
4
```

**Properties**

| Name | Type | Description |
|---|---|---|
| `name` | `str` | The probe's name. |
| `channels` | `list[int]` | The recording channel of every site, in site order. |
| `positions` | `np.ndarray` | Site positions `(sites, 3)` in µm: `x`, `y` (depth), `z`. |
| `shanks` | `list[int]` | The shank of every site. |

### `Sorting`

A spike sorting: units with their spike trains (sample indices), templates and quality
metrics.

Make one with [`load`](/dsp-kitchen/reference/python/pipeline/#load), `from_spikes` or [`synapse.detection.detect_recording`](/dsp-kitchen/plugins/synapse/reference/python/detection/#detect_recording).

**Examples**

```python
>>> import numpy as np
>>> import dspk
>>> s = dspk.synapse.io.Sorting.from_spikes([100, 900, 1500], [0, 1, 0], 30_000.0, 30_000)
>>> s.unit_ids
[0, 1]
```

**Properties**

| Name | Type | Description |
|---|---|---|
| `sorter_name` | `str` | Who made the sorting. |
| `sample_rate` | `float` | Sample rate of the recording, in Hz. |
| `total_samples` | `int` | Samples in the recording. |
| `unit_ids` | `list[int]` | The unit ids. |
| `probe` | `Probe \| None` | The probe, when the sorting has one. |
