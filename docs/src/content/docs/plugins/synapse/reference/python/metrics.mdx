## Functions

### `acg_refractory`

```python
acg_refractory(
    train,
    sample_rate: float,
    *,
    bin_ms: float = DEFAULT_REFRACTORY_BIN_MS,
    window_ms: float = DEFAULT_REFRACTORY_WINDOW_MS,
    ratio: float = DEFAULT_ACG_RATIO,
    probability: float = DEFAULT_ACG_PROBABILITY,
) -> dict
```

Kilosort4's test of whether a unit's auto-correlogram shows a refractory period.

**Parameters**

- **`train`** : `array_like`  
  Spike times, as sample indices.
- **`sample_rate`** : `float`  
  Sample rate in Hz.
- **`bin_ms`** : `float`, default `DEFAULT_REFRACTORY_BIN_MS` (1.0)  
  Bin width.
- **`window_ms`** : `float`, default `DEFAULT_REFRACTORY_WINDOW_MS` (500.0)  
  Lags counted.
- **`ratio`** : `float`, default `DEFAULT_ACG_RATIO` (0.2)  
  Refractory when the dip's ratio to the baseline (`R`) is below this...
- **`probability`** : `float`, default `DEFAULT_ACG_PROBABILITY` (0.2)  
  ...and its probability under a Poisson model (`Q`) is below this.

**Returns**

- `dict` — `ratio`, `probability`, `baseline`, `refractory` (the verdict).

### `amplitude_cutoff`

```python
amplitude_cutoff(
    amplitudes,
    *,
    bins: int = AMPLITUDE_CUTOFF_BINS,
    smoothing_bins: float = AMPLITUDE_CUTOFF_SMOOTHING,
    min_ratio: float = AMPLITUDE_CUTOFF_MIN_RATIO,
) -> float
```

Estimated fraction of a unit's spikes missed below the detection threshold.

From the histogram of its amplitudes, assuming it is symmetric around its peak.

**Parameters**

- **`amplitudes`** : `array_like`  
  The unit's spike amplitudes.
- **`bins`** : `int`, default `AMPLITUDE_CUTOFF_BINS` (100)  
  Histogram bins.
- **`smoothing_bins`** : `float`, default `AMPLITUDE_CUTOFF_SMOOTHING` (3.0)  
  Gaussian smoothing of the histogram, in bins.
- **`min_ratio`** : `float`, default `AMPLITUDE_CUTOFF_MIN_RATIO` (5.0)  
  Fewer spikes than this per bin: the estimate is not made (NaN).

**Returns**

- `float` — In `[0, 0.5]`.

Compares two sortings unit by unit, such as a sorter's against ground truth.

**Parameters**

- **`a`** : `Sorting`  
  The sortings (`a` taken as the truth).
- **`b`** : `Sorting`  
  The sortings (`a` taken as the truth).
- **`delta_ms`** : `float`, default `DEFAULT_MATCH_DELTA_MS` (0.4)  
  Spikes this close are a match.
- **`threshold`** : `float`, default `DEFAULT_AGREEMENT_THRESHOLD` (0.5)  
  Least agreement of a matched pair.

**Returns**

- `dict` — `agreement` `(units_a, units_b)`, `unit_ids_a`, `unit_ids_b`, `matched` (`(a, b, agreement)` pairs) and `well_detected` (units of `a`).

### `compare_trains`

```python
compare_trains(a, b, *, tolerance_samples: int) -> dict
```

Matches two spike trains one to one, within a tolerance.

**Parameters**

- **`a`** : `array_like`  
  Spike times, as sample indices (`a` taken as the truth).
- **`b`** : `array_like`  
  Spike times, as sample indices (`a` taken as the truth).
- **`tolerance_samples`** : `int`  
  Spikes this close are a match.

**Returns**

- `dict` — `matches`, `false_negatives`, `false_positives`, `agreement`, `precision`, `recall`.

**Examples**

```python
>>> import dspk
>>> out = dspk.synapse.metrics.compare_trains([100, 500, 900], [102, 500, 1300], tolerance_samples=5)
>>> out["matches"], out["false_negatives"], out["false_positives"]
(2, 1, 1)
```


Inter-spike-interval violations (Hill et al., 2011), as SpikeInterface's
`isi_violations_ratio`.

**Parameters**

- **`train`** : `array_like`

- **`total_samples`** : `int`

- **`sample_rate`** : `float`  
  Sample rate in Hz.

  Intervals shorter than this cannot occur (censored by detection).


### `stimulus_average`

```python
stimulus_average(
    data,
    stimulus_samples,
    sample_rate: float,
    *,
    pre_ms: float = 10.0,
    post_ms: float = 50.0,
    response_ms: tuple[float, float] = (2.0, 40.0),
    threshold_sigma: float = 3.0,
) -> dict
```

Stimulus-triggered average of a signal, and the evoked response on each channel.

**Parameters**

- **`data`** : `array_like`  
  Signal `(channels, samples)` in µV, converted to float32 on the host.
- **`stimulus_samples`** : `array_like`  
  Stimulus times, as sample indices.
- **`sample_rate`** : `float`  
  Sample rate in Hz.
- **`pre_ms`** : `float`, default `10.0`  
  Window before and after each stimulus.
- **`post_ms`** : `float`, default `50.0`  
  Window before and after each stimulus.
- **`response_ms`** : `float, float`, default `(2.0, 40.0)`  
  Where the evoked response is measured, after the stimulus.
- **`threshold_sigma`** : `float`, default `3.0`  
  The response starts where it first exceeds this many baseline standard deviations.

**Returns**

- `dict` — `time_ms`, `mean` / `std` / `se` `(channels, samples)`, `trials`; per channel the evoked potential: `mep_onset_ms`, `mep_peak_to_peak_uv`, `mep_rms_uv`, `mep_area_uv_ms`.
