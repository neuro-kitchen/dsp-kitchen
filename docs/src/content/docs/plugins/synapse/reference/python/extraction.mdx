## Functions

### `snippets`

```python
snippets(
    data,
    spikes: dict,
    probe: Probe,
    sample_rate: float,
    *,
    k: int = DEFAULT_K_NEIGHBORS,
    pre_ms: float = DEFAULT_PRE_MS,
    post_ms: float = DEFAULT_POST_MS,
    sinc_shift: bool = False,
) -> dict
```

`[t − pre_ms, t + post_ms)` around each spike of `spikes` (`samples`, `channels`) on
its `k` nearest channels, from `data` `(channels, samples)`; `sinc_shift` realigns each
to its sub-sample trough. Spikes too near an edge are skipped (`kept`: the input indices).
`waveforms` `(spikes, k, samples)`, `channels` `(spikes, k)`, `centers`, `offsets`.

**Parameters**

- **`data`**
- **`spikes`** : `dict`
- **`probe`** : `Probe`
- **`sample_rate`** : `float`
- **`k`** : `int`, default `DEFAULT_K_NEIGHBORS` (4)
- **`pre_ms`** : `float`, default `DEFAULT_PRE_MS` (1.0)
- **`post_ms`** : `float`, default `DEFAULT_POST_MS` (2.0)
- **`sinc_shift`** : `bool`, default `False`
