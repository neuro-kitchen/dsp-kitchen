Waveform features: shape (morphology), Haar wavelet coefficients, and the conduction velocity of
an HD-EMG motor unit. Principal components are [`ops.linalg.PCA`](/dsp-kitchen/reference/python/ops-linalg/#pca).

| | |
|---|---|
| [`conduction_velocity`](#conduction_velocity) | Muscle-fibre conduction velocity from an HD-EMG template `(rows · cols, samples)` (row-major grid, `pitch_um` apart). |
| [`haar_wavelet`](#haar_wavelet) | Multi-level Haar wavelet transform (coefficients concatenated, approximation first). |
| [`morphology`](#morphology) | Per waveform (rows of `(spikes, samples)`, one channel). |
