Clustering of feature points `(n, d)` (spike features, PCs, positions): k-means, HDBSCAN and
Gaussian mixtures on the runtime's device; density peaks and KDE valley merging on the host; and
the random choice of peaks sorters cluster on. Labels are `int64` (`-1`: noise / outlier).

| | |
|---|---|
| [`density_peaks`](#density_peaks) | Rodriguez–Laio density peaks. |
| [`gmm`](#gmm) | A Gaussian mixture with its number of components chosen by BIC in `k_min..=k_max`. |
| [`hdbscan`](#hdbscan) | HDBSCAN labels (as the `hdbscan` package. |
| [`kde_merge`](#kde_merge) | k-means over-clustering (`initial_k`), then merges of clusters with no density valley between them. |
| [`kmeans`](#kmeans) | k-means (k-means++ starts; the best of `n_init`). |
| [`subsample_peaks`](#subsample_peaks) | Indices of `n_peaks` peaks chosen at random (in total, or of each channel), by sample. |

### `gmm`

```python
gmm(
    points,
    *,
    k_min: int = DEFAULT_GMM_K_MIN,
    k_max: int = DEFAULT_GMM_K_MAX,
    covariance: str = 'full',
    max_iterations: int = DEFAULT_GMM_MAX_ITERATIONS,
    tolerance: float = DEFAULT_GMM_TOLERANCE,
    regularization: float = DEFAULT_GMM_REGULARIZATION,
    outlier_mahalanobis_sq: float | None = None,
    mask=None,
    runtime: str | None = None,
) -> dict
```

A Gaussian mixture with its number of components chosen by BIC in `k_min..=k_max`.
`covariance`: `full`, `diagonal` or `masked` (KlustaKwik's masked EM, with `mask`
`(n, d)`). Returns `labels`, `weights`, `means`, `covariances`,
`responsibilities`, `mahalanobis_sq`, `log_likelihood`, `bic`.

**Parameters**

- **`points`**
- **`k_min`** : `int`, default `DEFAULT_GMM_K_MIN` (1)
- **`k_max`** : `int`, default `DEFAULT_GMM_K_MAX` (8)
- **`covariance`** : `str`, default `'full'`
- **`max_iterations`** : `int`, default `DEFAULT_GMM_MAX_ITERATIONS` (100)
- **`tolerance`** : `float`, default `DEFAULT_GMM_TOLERANCE` (0.001)
- **`regularization`** : `float`, default `DEFAULT_GMM_REGULARIZATION` (0.0001)
- **`outlier_mahalanobis_sq`** : `float | None`, default `None`
- **`mask`**, default `None`
- **`runtime`** : `str | None`, default `None`
