### `fir`

```python
fir(
    taps,
    *,
    centered: bool = False,
    edge: str = FIR_DEFAULT_EDGE,
) -> Stage
```

An FIR filter with explicit taps, causal or centred.

**Parameters**

- **`taps`** : `array_like`  
  Filter taps (1-D), e.g. from [`ops.filter.firwin`](/dsp-kitchen/reference/python/ops-filter/#firwin).
- **`centered`** : `bool`, default `False`  
  `False`: causal. `True`: the taps (an odd number) centred on each sample.
- **`edge`** : `{"zeros", "odd", "reflect", "nearest"}`, default `FIR_DEFAULT_EDGE` ('zeros')  
  What the samples past each end are taken to be.

**Returns**

- `Stage`

**Raises**

- `ValueError`: For empty `taps` or an even number of centred taps.

**Notes**

In `Pipeline(stream=True)` the taps' history is not carried from one chunk to the next: run
it on independent chunks with `settling` of context, which is exact for a FIR.

### `iir`

```python
iir(
    band: str,
    cutoff: float | Sequence[float],
    *,
    order: int = DEFAULT_ORDER,
    design: str = 'butterworth',
    ripple_db: float | None = None,
    mode: str = 'forward_backward',
    start: str = 'rest',
) -> Stage
```

An IIR filter, as [`ops.filter.iir`](/dsp-kitchen/reference/python/ops-filter/#iir); the pipeline gives the sample rate.

**Parameters**

- **`band`** : `{"lowpass", "highpass", "bandpass", "bandstop"}`  
  The band the filter passes (or stops).
- **`cutoff`** : `float or (float, float)`  
  Cutoff in Hz: one, or `(low, high)` for the band filters.
- **`order`** : `int`, default `DEFAULT_ORDER` (5)  
  Filter order.
- **`design`** : `{"butterworth", "chebyshev1", "bessel"}`, default `'butterworth'`  
  The filter family.
- **`ripple_db`** : `float`, default `None`  
  Passband ripple in dB; `"chebyshev1"` needs it.
- **`mode`** : `{"forward_backward", "forward"}`, default `'forward_backward'`  
  `"forward_backward"`: zero phase (windowed runs only). `"forward"`: causal, the mode `stream=True` needs.
- **`start`** : `{"rest", "steady_state"}`, default `'rest'`  
  Where a `"forward"` pass starts, as in [`ops.filter.iir`](/dsp-kitchen/reference/python/ops-filter/#iir).

**Returns**

- `Stage`

**Raises**

- `ValueError`: For an invalid design, `mode` or `start`.

### `reorder_channels`

```python
reorder_channels(order: Sequence[int]) -> Stage
```

The channels in a new order: output channel `i` is input channel `order[i]`.

Every channel is used once, so the channel count stays. To drop channels, use
[`ops.layout.remap`](/dsp-kitchen/reference/python/ops-layout/#remap), or a `remap` node right after `read` or before `write` in a
pipeline spec.

**Parameters**

- **`order`** : `sequence of int`  
  A permutation of `0..channels`.

- `Stage`

**Raises**

- `ValueError`: When `order` is not a permutation.
