Channels in a new order on the device, and channel maps.

A channel map says which input channel becomes which output channel, as pairs (like a hardware
channel mapper). `base` is 0, or 1 for 1-based numbers (TDT, MATLAB):


<Tabs syncKey="format">
<TabItem label="TOML">

```toml
[remap]
base = 0
pairs = [
  { from = 4, to = 0, name = "A1" },
  { from = 2, to = 1, name = "A2" },
]
```

</TabItem>
<TabItem label="JSON">

```json
{
  "remap": {
    "base": 0,
    "pairs": [
      {"from": 4, "to": 0, "name": "A1"},
      {"from": 2, "to": 1, "name": "A2"}
    ]
  }
}
```

</TabItem>
</Tabs>

Every output channel `0..n` gets exactly one input; inputs left out are dropped; the same input
twice is refused; names are optional. A map is a dict `{"base": 0, "pairs": [...]}` (or the
file's `{"remap": {...}}`), a `.toml` / `.json` path, or a list of pairs. In a pipeline spec
the same map is a `{"op": "remap", "pairs": [...]}` (or `"path": "map.toml"`) node.

as_map(map: MapLike, *, base: int = DEFAULT_BASE) -> ChannelMap

Any form of channel map as one checked dict.

**Parameters**

- **`map`** : `dict, list of dict, str or os.PathLike`  
  A channel map: a `{"base", "pairs"}` dict (or a file's `{"remap": {...}}`), a list of `{"from", "to", "name"}` pairs, or the path of a `.toml` / `.json` map file.

**Raises**

- `ValueError`: When the map is invalid: an output without an input, an input used twice, ...

### `gather_channels`

```python
gather_channels(
    data,
    order: Sequence[int],
    *,
    runtime: str | None = None,
) -> np.ndarray
```

Rows of `data` in a new order, on the device: row `i` is channel `order[i]`.

Channels may be left out or repeated.

**Parameters**

- **`data`** : `array_like`  
  Signal `(channels, samples)`. float32, int8, int16, uint16 and int32 arrays go to the device as they are and are converted there; other dtypes and lists become float32 first.
- **`order`** : `sequence of int`  
  Input channel (0-based) of each output row.
- **`runtime`** : `str`, default `None`  
  A runtime from [`runtime.available`](/dsp-kitchen/reference/python/runtime/#available) (`"cuda"`, `"hip"`, `"wgpu"`, `"cpu"`) for this call. By default: the one chosen with [`runtime.set`](/dsp-kitchen/reference/python/runtime/#set), else `DSPK_RUNTIME`, else the first available (GPUs first).

**Returns**

- `np.ndarray` — `(len(order), samples)`, float32.

**Raises**

- `ValueError`: When `order` names a channel `data` does not have.
- `RuntimeError`: When the runtime has no device.

**Examples**

```python
>>> import numpy as np
>>> import dspk
>>> x = np.random.default_rng(0).standard_normal((4, 30_000)).astype(np.float32)
>>> dspk.ops.layout.gather_channels(x, [3, 0]).shape
(2, 30000)
```

### `map_order`

```python
map_order(
    map: MapLike,
    channels: int | None = None,
) -> tuple[list[int], list[str | None]]
```

The input channel and the name of every output channel of a map.

**Parameters**

- **`map`** : `dict, list of dict, str or os.PathLike`  
  A channel map: a `{"base", "pairs"}` dict (or a file's `{"remap": {...}}`), a list of `{"from", "to", "name"}` pairs, or the path of a `.toml` / `.json` map file.
- **`channels`** : `int`, default `None`  
  Number of input channels, to check the map against.

**Returns**

- `list of int` — The input channel (0-based) of each output channel.
- `list of str or None` — Each output channel's name (`None` when unnamed).

**Raises**

- `ValueError`: When the map is invalid or reads a channel past `channels`.

**Examples**

```python
>>> import dspk
>>> dspk.ops.layout.map_order([{"from": 2, "to": 0}, {"from": 0, "to": 1}])
([2, 0], [None, None])
```

### `remap`

```python
remap(
    data,
    map: MapLike,
    *,
    runtime: str | None = None,
) -> np.ndarray
```

`data` through a channel map, on the device.

Inputs the map leaves out are dropped; [`map_order`](/dsp-kitchen/reference/python/ops-layout/#map_order) gives the outputs' names.

**Parameters**

- **`data`** : `array_like`  
  Signal `(channels, samples)`. float32, int8, int16, uint16 and int32 arrays go to the device as they are and are converted there; other dtypes and lists become float32 first.
- **`map`** : `dict, list of dict, str or os.PathLike`  
  A channel map: a `{"base", "pairs"}` dict (or a file's `{"remap": {...}}`), a list of `{"from", "to", "name"}` pairs, or the path of a `.toml` / `.json` map file.
- **`runtime`** : `str`, default `None`  
  A runtime from [`runtime.available`](/dsp-kitchen/reference/python/runtime/#available) (`"cuda"`, `"hip"`, `"wgpu"`, `"cpu"`) for this call. By default: the one chosen with [`runtime.set`](/dsp-kitchen/reference/python/runtime/#set), else `DSPK_RUNTIME`, else the first available (GPUs first).

**Returns**

- `np.ndarray` — `(outputs, samples)`, float32.

**Raises**

- `ValueError`: When the map is invalid or reads a channel `data` does not have.
- `RuntimeError`: When the runtime has no device.

**Examples**

```python
>>> import numpy as np
>>> import dspk
>>> x = np.random.default_rng(0).standard_normal((4, 30_000)).astype(np.float32)
>>> dspk.ops.layout.remap(x, [{"from": 3, "to": 0}, {"from": 1, "to": 1}]).shape
(2, 30000)
```
